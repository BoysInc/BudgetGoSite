Guide de configuration · environ 2 minutes chacun

Enregistrez vos dépenses à l’instant où elles ont lieu.

Les automatisations Raccourcis d’Apple peuvent envoyer les paiements Apple Pay et les alertes SMS bancaires directement à BudgetGo, pour que les transactions arrivent dans vos données sans rien saisir. Tout s’exécute sur votre iPhone.

Avant de commencer

Trois vérifications rapides.

  • BudgetGo est installéTéléchargez-le depuis l’App Store et connectez-vous une fois pour que ses actions apparaissent dans Raccourcis.
  • Raccourcis est sur votre iPhoneL’app Raccourcis d’Apple est préinstallée sur iOS 17 et versions ultérieures.
  • Les imports sont activésDans BudgetGo, ouvrez Data Hub et activez les imports Wallet ou SMS. S’ils sont désactivés, BudgetGo ignore tout ce que l’automatisation envoie.

Apple Wallet

Enregistrez automatiquement les paiements Apple Pay.

Cette automatisation s’exécute chaque fois que vous payez avec une carte Wallet, puis envoie le montant et le commerçant à l’action Add Transaction to Budget Go de BudgetGo.

  1. 1

    Ouvrir Raccourcis

    Trouvez et ouvrez l’app Raccourcis sur votre iPhone.

  2. 2

    Créer une automatisation personnelle

    Ouvrez l’onglet Automation, puis touchez + pour créer une nouvelle automatisation personnelle.

  3. 3

    Choisir le déclencheur Wallet

    1. Cherchez Transaction (affiché Wallet sur certaines versions d’iOS) et sélectionnez-le.
    2. Sélectionnez chaque carte que BudgetGo doit suivre.
    3. Choisissez Run Immediately pour que l’automatisation n’attende jamais de confirmation, puis touchez Next.
  4. 4

    Ajouter l’action BudgetGo

    Touchez New Blank Automation, cherchez BudgetGo et choisissez Add Transaction to Budget Go.

  5. 5

    Relier les détails du paiement

    1. Touchez le champ Amount, choisissez Select Variable, puis Shortcut Input.
    2. Touchez le Shortcut Input inséré et changez-le en Amount.
    3. Répétez pour Merchant en choisissant Merchant dans Shortcut Input.
    4. Touchez le bouton de lecture pour tester, puis touchez Done.

    La devise est facultative. Laissez vide pour utiliser la devise par défaut de BudgetGo, ou saisissez un code comme USD, EUR ou NGN.

  6. 6

    Vérifier dans BudgetGo

    Dans BudgetGo, ouvrez Data Hub et touchez Wallet Automation. Vérifiez que Apple Wallet tracking est activé, puis touchez Run test shortcut. Le statut passe à vérifié dès que BudgetGo reçoit un paiement de votre automatisation.

Messages

Transformez les alertes SMS bancaires en transactions.

Si votre banque vous envoie des SMS pour les paiements par carte et les virements, une automatisation Messages peut transmettre chaque alerte à l’action Import SMS Transaction de BudgetGo. BudgetGo lit le message sur votre appareil et ne crée une transaction que s’il reconnaît une alerte financière.

  1. 1

    Créer une automatisation Message

    Dans Raccourcis, ouvrez l’onglet Automation, touchez + et choisissez Message.

  2. 2

    La limiter aux messages de votre banque

    1. Touchez Sender et choisissez le contact ou le numéro de votre banque, ou utilisez Message Contains avec un mot présent dans chaque alerte, comme le nom de votre banque.
    2. Choisissez Run Immediately, puis touchez Next.

    Gardez le filtre étroit. Cibler uniquement votre banque garde vos conversations personnelles hors de BudgetGo.

  3. 3

    Ajouter l’action BudgetGo

    Touchez New Blank Automation, cherchez BudgetGo et choisissez Import SMS Transaction.

  4. 4

    Transmettre le message

    1. Touchez le champ Message, choisissez Select Variable, sélectionnez Shortcut Input et réglez-le sur Content.
    2. Touchez le champ Sender et choisissez Shortcut Input réglé sur Sender. C’est facultatif, mais cela aide BudgetGo à identifier votre banque.
    3. Touchez Done.
  5. 5

    Tester

    Attendez votre prochaine alerte bancaire, ou ouvrez le détail de l’automatisation dans Data Hub de BudgetGo et touchez Test connection. Revenez ensuite dans BudgetGo pour vérifier la transaction importée.

Dépannage

Si une transaction n’apparaît pas.

Je ne trouve pas les actions BudgetGo dans Raccourcis

Ouvrez BudgetGo une fois après l’installation ou la mise à jour pour qu’iOS enregistre ses actions, puis cherchez de nouveau « BudgetGo » dans Raccourcis.

J’ai reçu une notification « Transaction Import Failed »

L’automatisation Wallet a envoyé un montant ou un commerçant vide. Rouvrez l’automatisation et vérifiez que les deux champs utilisent Shortcut Input avec Amount et Merchant sélectionnés.

L’automatisation demande confirmation avant de s’exécuter

Modifiez l’automatisation dans Raccourcis et passez de Run After Confirmation à Run Immediately.

Une alerte SMS n’a pas créé de transaction

Seuls les messages financiers pris en charge produisent des transactions. Vérifiez que les imports sont activés dans Data Hub et que le champ Message utilise le contenu du message.

Toujours bloqué ? Écrivez à support@budgetgo.ai ou utilisez la page d’assistance.
