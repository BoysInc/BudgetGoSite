Guía de configuración · unos 2 minutos cada una

Registra tus gastos en el momento en que ocurren.

Las automatizaciones de Atajos de Apple pueden enviar pagos de Apple Pay y alertas SMS del banco directamente a BudgetGo, para que las transacciones lleguen a tus registros sin escribir nada. Todo se ejecuta en tu iPhone.

Antes de empezar

Tres comprobaciones rápidas.

  • BudgetGo está instaladoDescárgalo de la App Store e inicia sesión una vez para que sus acciones aparezcan en Atajos.
  • Atajos está en tu iPhoneLa app Atajos de Apple viene preinstalada en iOS 17 y posteriores.
  • Las importaciones están activadasEn BudgetGo, abre Data Hub y activa las importaciones de Wallet o SMS. Si están desactivadas, BudgetGo ignora todo lo que envíe la automatización.

Apple Wallet

Registra los pagos con Apple Pay automáticamente.

Esta automatización se ejecuta cada vez que pagas con una tarjeta de Wallet y envía el importe y el comercio a la acción Add Transaction to Budget Go de BudgetGo.

  1. 1

    Abre Atajos

    Busca y abre la app Atajos en tu iPhone.

  2. 2

    Crea una automatización personal

    Abre la pestaña Automation y toca + para crear una nueva automatización personal.

  3. 3

    Elige el disparador de Wallet

    1. Busca Transaction (aparece como Wallet en algunas versiones de iOS) y selecciónalo.
    2. Selecciona todas las tarjetas que quieras que BudgetGo registre.
    3. Elige Run Immediately para que la automatización nunca espere confirmación y toca Next.
  4. 4

    Añade la acción de BudgetGo

    Toca New Blank Automation, busca BudgetGo y elige Add Transaction to Budget Go.

  5. 5

    Conecta los datos del pago

    1. Toca el campo Amount, elige Select Variable y luego Shortcut Input.
    2. Toca el Shortcut Input insertado y cámbialo a Amount.
    3. Repite con Merchant, eligiendo Merchant desde Shortcut Input.
    4. Toca el botón de reproducir para probarlo y luego toca Done.

    La moneda es opcional. Déjala vacía para usar la moneda predeterminada de BudgetGo, o escribe un código como USD, EUR o NGN.

  6. 6

    Compruébalo en BudgetGo

    En BudgetGo, abre Data Hub y toca Wallet Automation. Asegúrate de que Apple Wallet tracking esté activado y toca Run test shortcut. El estado cambia a verificado cuando BudgetGo recibe un pago de tu automatización.

Mensajes

Convierte las alertas SMS del banco en transacciones.

Si tu banco te envía mensajes sobre pagos con tarjeta y transferencias, una automatización de Mensajes puede pasar cada alerta a la acción Import SMS Transaction de BudgetGo. BudgetGo lee el mensaje en tu dispositivo y crea una transacción solo cuando reconoce una alerta financiera.

  1. 1

    Crea una automatización de Mensajes

    En Atajos, abre la pestaña Automation, toca + y elige Message.

  2. 2

    Limítala a los mensajes de tu banco

    1. Toca Sender y elige el contacto o número de tu banco, o usa Message Contains con una palabra que aparezca en todas las alertas, como el nombre de tu banco.
    2. Elige Run Immediately y toca Next.

    Mantén el filtro estrecho. Si solo coincide con tu banco, tus conversaciones personales quedan fuera de BudgetGo.

  3. 3

    Añade la acción de BudgetGo

    Toca New Blank Automation, busca BudgetGo y elige Import SMS Transaction.

  4. 4

    Pasa el mensaje

    1. Toca el campo Message, elige Select Variable, selecciona Shortcut Input y ajústalo a Content.
    2. Toca el campo Sender y elige Shortcut Input ajustado a Sender. Es opcional, pero ayuda a BudgetGo a identificar tu banco.
    3. Toca Done.
  5. 5

    Pruébalo

    Espera a tu próxima alerta del banco, o abre el detalle de la automatización en Data Hub de BudgetGo y toca Test connection. Después vuelve a BudgetGo para revisar la transacción importada.

Solución de problemas

Si una transacción no aparece.

No encuentro las acciones de BudgetGo en Atajos

Abre BudgetGo una vez después de instalarlo o actualizarlo para que iOS registre sus acciones y vuelve a buscar "BudgetGo" en Atajos.

Recibí una notificación de "Transaction Import Failed"

La automatización de Wallet envió un importe o comercio vacío. Vuelve a abrir la automatización y comprueba que ambos campos usen Shortcut Input con Amount y Merchant seleccionados.

La automatización pregunta antes de ejecutarse

Edita la automatización en Atajos y cámbiala de Run After Confirmation a Run Immediately.

Una alerta SMS no creó una transacción

Solo los mensajes financieros compatibles generan transacciones. Comprueba que las importaciones estén activadas en Data Hub y que el campo Message use el contenido del mensaje.
