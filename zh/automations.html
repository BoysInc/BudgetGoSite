在支出发生的那一刻就记录下来。

Apple 快捷指令自动化可以把 Apple Pay 付款和银行短信提醒直接发送到 BudgetGo，交易无需输入就会进入你的记录。一切都在你的 iPhone 上运行。

  3. BudgetGo 自动记录金额、商家和类别

开始之前

三项快速检查。

  • 已安装 BudgetGo从 App Store 下载并登录一次，这样它的操作才会出现在快捷指令中。
  • 你的 iPhone 上有快捷指令Apple 的快捷指令应用已预装在 iOS 17 及更高版本中。
  • 已开启导入在 BudgetGo 中打开 Data Hub，并开启 Wallet 或短信导入。关闭时，BudgetGo 会忽略自动化发送的任何内容。

Apple Wallet

自动记录 Apple Pay 付款。

每次你用钱包中的卡片付款时，此自动化都会运行，并把金额和商家发送给 BudgetGo 的 Add Transaction to Budget Go 操作。

  1. 1

    打开快捷指令

    在 iPhone 上找到并打开快捷指令应用。

  2. 2

    创建个人自动化

    打开 Automation 标签页，然后点按 + 创建新的个人自动化。

  3. 3

    选择 Wallet 触发器

    1. 搜索 Transaction（在某些 iOS 版本中显示为 Wallet）并选择它。
    2. 选择你希望 BudgetGo 追踪的每一张卡片。
    3. 选择 Run Immediately，让自动化无需等待确认，然后点按 Next。
  4. 4

    添加 BudgetGo 操作

    点按 New Blank Automation，搜索 BudgetGo，选择 Add Transaction to Budget Go。

  5. 5

    连接付款详情

    1. 点按 Amount 字段，选择 Select Variable，然后选取 Shortcut Input。
    2. 点按插入的 Shortcut Input，并将其改为 Amount。
    3. 对 Merchant 重复此步骤，从 Shortcut Input 中选择 Merchant。
    4. 点按播放按钮进行测试，然后点按 Done。

    币种为可选项。留空则使用 BudgetGo 的默认币种，或输入 USD、EUR、NGN 等代码。

  6. 6

    在 BudgetGo 中检查

    在 BudgetGo 中打开 Data Hub，点按 Wallet Automation。确保 Apple Wallet tracking 已开启，然后点按 Run test shortcut。当 BudgetGo 收到来自你的自动化的付款后，状态会变为已验证。

信息

把银行短信提醒变成交易。

如果你的银行会就刷卡付款和转账给你发短信，“信息”自动化可以把每条提醒传给 BudgetGo 的 Import SMS Transaction 操作。BudgetGo 在你的设备上读取信息，只有识别为财务提醒时才会创建交易。

  1. 1

    创建信息自动化

    在快捷指令中，打开 Automation 标签页，点按 +，然后选择 Message。

  2. 2

    限定为你银行的信息

    1. 点按 Sender 并选择你银行的联系人或号码，或使用 Message Contains，填入每条提醒都会出现的词，例如银行名称。
    2. 选择 Run Immediately，然后点按 Next。

    让筛选条件尽量精确。只匹配你的银行，可以避免个人对话进入 BudgetGo。

  3. 3

    添加 BudgetGo 操作

    点按 New Blank Automation，搜索 BudgetGo，选择 Import SMS Transaction。

  4. 4

    传入信息

    1. 点按 Message 字段，选择 Select Variable，选取 Shortcut Input，并设为 Content。
    2. 点按 Sender 字段，选择 Shortcut Input 并设为 Sender。此项可选，但有助于 BudgetGo 识别你的银行。
    3. 点按 Done。
  5. 5

    测试

    等待下一条银行提醒，或在 BudgetGo 的 Data Hub 中打开该自动化的详情并点按 Test connection。然后回到 BudgetGo 查看导入的交易。

故障排查

如果交易没有出现。

在快捷指令中找不到 BudgetGo 的操作

安装或更新后先打开一次 BudgetGo，让 iOS 注册其操作，然后在快捷指令中再次搜索“BudgetGo”。

我收到了“Transaction Import Failed”通知

Wallet 自动化发送了空的金额或商家。请重新打开自动化，确保两个字段都使用 Shortcut Input，并分别选中 Amount 和 Merchant。

自动化运行前会先询问

在快捷指令中编辑该自动化，把 Run After Confirmation 改为 Run Immediately。

短信提醒没有创建交易

只有受支持的财务信息才会产生交易。请检查 Data Hub 中的导入已开启，并确保 Message 字段使用信息的 Content。

仍然没解决？请发送邮件至 support@budgetgo.ai，或使用支持页面。
