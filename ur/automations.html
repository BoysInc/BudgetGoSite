Apple Wallet

Apple Pay ادائیگیاں خودکار طور پر درج کریں۔

یہ آٹومیشن ہر بار چلتی ہے جب آپ Wallet کارڈ سے ادائیگی کرتے ہیں، اور رقم اور دکان کو BudgetGo کے Add Transaction to Budget Go ایکشن کو بھیجتی ہے۔

  1. 1

    شارٹ کٹس کھولیں

    اپنے iPhone پر شارٹ کٹس ایپ تلاش کر کے کھولیں۔

  2. 2

    ایک ذاتی آٹومیشن بنائیں

    Automation ٹیب کھولیں، پھر نئی ذاتی آٹومیشن بنانے کے لیے + پر ٹیپ کریں۔

  3. 3

    Wallet ٹرگر منتخب کریں

    1. Transaction تلاش کریں (بعض iOS ورژنز میں Wallet کے طور پر نظر آتا ہے) اور اسے منتخب کریں۔
    2. ہر وہ کارڈ منتخب کریں جسے BudgetGo کو ٹریک کرنا ہے۔
    3. Run Immediately منتخب کریں تاکہ آٹومیشن تصدیق کا انتظار نہ کرے، پھر Next پر ٹیپ کریں۔
  4. 4

    BudgetGo ایکشن شامل کریں

    New Blank Automation پر ٹیپ کریں، BudgetGo تلاش کریں اور Add Transaction to Budget Go منتخب کریں۔

  5. 5

    ادائیگی کی تفصیلات جوڑیں

    1. Amount فیلڈ پر ٹیپ کریں، Select Variable منتخب کریں، پھر Shortcut Input چنیں۔
    2. داخل کیے گئے Shortcut Input پر ٹیپ کریں اور اسے Amount میں بدل دیں۔
    3. Merchant کے لیے دہرائیں، Shortcut Input میں سے Merchant منتخب کریں۔
    4. ٹیسٹ کے لیے پلے بٹن پر ٹیپ کریں، پھر Done پر ٹیپ کریں۔

    کرنسی اختیاری ہے۔ BudgetGo کی ڈیفالٹ کرنسی کے لیے خالی چھوڑیں، یا USD، EUR یا NGN جیسا کوڈ درج کریں۔

  6. 6

    BudgetGo میں جانچیں

    BudgetGo میں Data Hub کھولیں اور Wallet Automation پر ٹیپ کریں۔ یقینی بنائیں کہ Apple Wallet tracking آن ہے، پھر Run test shortcut پر ٹیپ کریں۔ BudgetGo کو آپ کی آٹومیشن سے ادائیگی ملتے ہی اسٹیٹس تصدیق شدہ ہو جاتا ہے۔

پیغامات

بینک SMS الرٹس کو لین دین میں بدلیں۔

اگر آپ کا بینک کارڈ ادائیگیوں اور ٹرانسفرز کے بارے میں ٹیکسٹ بھیجتا ہے تو پیغامات کی آٹومیشن ہر الرٹ کو BudgetGo کے Import SMS Transaction ایکشن تک پہنچا سکتی ہے۔ BudgetGo پیغام آپ کے آلے پر پڑھتا ہے اور لین دین صرف تب بناتا ہے جب وہ کسی مالی الرٹ کو پہچان لے۔

  1. 1

    پیغام کی آٹومیشن بنائیں

    شارٹ کٹس میں Automation ٹیب کھولیں، + پر ٹیپ کریں اور Message منتخب کریں۔

  2. 2

    اسے اپنے بینک کے پیغامات تک محدود کریں

    1. Sender پر ٹیپ کر کے اپنے بینک کا رابطہ یا نمبر منتخب کریں، یا ہر الرٹ میں آنے والے کسی لفظ، جیسے بینک کے نام، کے ساتھ Message Contains استعمال کریں۔
    2. Run Immediately منتخب کریں، پھر Next پر ٹیپ کریں۔

    فلٹر کو تنگ رکھیں۔ صرف اپنے بینک سے مطابقت رکھنے سے ذاتی گفتگو BudgetGo سے باہر رہتی ہے۔

  3. 3

    BudgetGo ایکشن شامل کریں

    New Blank Automation پر ٹیپ کریں، BudgetGo تلاش کریں اور Import SMS Transaction منتخب کریں۔

  4. 4

    پیغام آگے بھیجیں

    1. Message فیلڈ پر ٹیپ کریں، Select Variable منتخب کریں، Shortcut Input چنیں اور اسے Content پر سیٹ کریں۔
    2. Sender فیلڈ پر ٹیپ کریں اور Sender پر سیٹ Shortcut Input منتخب کریں۔ یہ اختیاری ہے مگر BudgetGo کو آپ کا بینک پہچاننے میں مدد دیتا ہے۔
    3. Done پر ٹیپ کریں۔
  5. 5

    ٹیسٹ کریں

    اپنے اگلے بینک الرٹ کا انتظار کریں، یا BudgetGo کے Data Hub میں آٹومیشن کی تفصیل کھول کر Test connection پر ٹیپ کریں۔ پھر امپورٹ شدہ لین دین دیکھنے کے لیے BudgetGo میں واپس جائیں۔

مسائل کا حل

اگر کوئی لین دین ظاہر نہ ہو۔

مجھے شارٹ کٹس میں BudgetGo کے ایکشنز نہیں مل رہے

انسٹال یا اپڈیٹ کرنے کے بعد BudgetGo کو ایک بار کھولیں تاکہ iOS اس کے ایکشنز رجسٹر کر لے، پھر شارٹ کٹس میں دوبارہ "BudgetGo" تلاش کریں۔

مجھے "Transaction Import Failed" کی اطلاع ملی

Wallet آٹومیشن نے خالی رقم یا دکان بھیجی۔ آٹومیشن دوبارہ کھولیں اور یقینی بنائیں کہ دونوں فیلڈز Shortcut Input استعمال کرتی ہیں اور Amount و Merchant منتخب ہیں۔

آٹومیشن چلنے سے پہلے پوچھتی ہے

شارٹ کٹس میں آٹومیشن میں ترمیم کریں اور Run After Confirmation سے Run Immediately پر بدلیں۔

ایک SMS الرٹ سے لین دین نہیں بنا

صرف معاون مالی پیغامات سے لین دین بنتے ہیں۔ جانچیں کہ Data Hub میں امپورٹس آن ہیں اور Message فیلڈ پیغام کا Content استعمال کرتی ہے۔
