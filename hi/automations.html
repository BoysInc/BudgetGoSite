खर्च को उसी पल दर्ज करें जब वह होता है।

Apple शॉर्टकट्स ऑटोमेशन Apple Pay भुगतान और बैंक SMS अलर्ट सीधे BudgetGo को भेज सकते हैं, ताकि बिना कुछ टाइप किए लेन-देन आपके रिकॉर्ड में आ जाएँ। सब कुछ आपके iPhone पर चलता है।

Apple Pay payments बैंक SMS अलर्ट समस्या निवारण
  1. आप भुगतान करते हैं या बैंक का टेक्स्ट आता हैApple Pay टैप या SMS अलर्ट
  2. शॉर्टकट्स तुरंत चलता हैआपका निजी ऑटोमेशन
  3. BudgetGo दर्ज करता हैराशि, दुकान और श्रेणी

शुरू करने से पहले

तीन त्वरित जाँचें।

  • BudgetGo इंस्टॉल हैइसे App Store से डाउनलोड करें और एक बार साइन इन करें ताकि इसकी कार्रवाइयाँ शॉर्टकट्स में दिखें।
  • शॉर्टकट्स आपके iPhone पर हैApple का शॉर्टकट्स ऐप iOS 17 और उसके बाद के वर्शन में पहले से इंस्टॉल आता है।
  • इम्पोर्ट चालू हैंBudgetGo में Data Hub खोलें और Wallet या SMS इम्पोर्ट चालू करें। बंद होने पर BudgetGo ऑटोमेशन से भेजी गई हर चीज़ को अनदेखा कर देता है।

Apple Wallet

Apple Pay भुगतान अपने-आप दर्ज करें।

यह ऑटोमेशन हर बार चलता है जब आप Wallet कार्ड टैप करके भुगतान करते हैं, और राशि व दुकान को BudgetGo की Add Transaction to Budget Go कार्रवाई को भेजता है।

  1. 1

    शॉर्टकट्स खोलें

    अपने iPhone पर शॉर्टकट्स ऐप खोजें और खोलें।

  2. 2

    एक निजी ऑटोमेशन बनाएँ

    Automation टैब खोलें, फिर नया निजी ऑटोमेशन बनाने के लिए + पर टैप करें।

  3. 3

    Wallet ट्रिगर चुनें

    1. Transaction खोजें (कुछ iOS वर्शन में यह Wallet के रूप में दिखता है) और उसे चुनें।
    2. हर वह कार्ड चुनें जिसे BudgetGo को ट्रैक करना है।
    3. Run Immediately चुनें ताकि ऑटोमेशन कभी पुष्टि का इंतज़ार न करे, फिर Next पर टैप करें।
  4. 4

    BudgetGo कार्रवाई जोड़ें

    New Blank Automation पर टैप करें, BudgetGo खोजें और Add Transaction to Budget Go चुनें।

  5. 5

    भुगतान का विवरण जोड़ें

    1. Amount फ़ील्ड पर टैप करें, Select Variable चुनें, फिर Shortcut Input चुनें।
    2. डाले गए Shortcut Input पर टैप करें और उसे Amount में बदलें।
    3. Merchant के लिए दोहराएँ, Shortcut Input में से Merchant चुनें।
    4. टेस्ट करने के लिए प्ले बटन पर टैप करें, फिर Done पर टैप करें।

    मुद्रा वैकल्पिक है। BudgetGo की डिफ़ॉल्ट मुद्रा के लिए खाली छोड़ें, या USD, EUR या NGN जैसा कोड दर्ज करें।

  6. 6

    BudgetGo में जाँचें

    BudgetGo में Data Hub खोलें और Wallet Automation पर टैप करें। सुनिश्चित करें कि Apple Wallet tracking चालू है, फिर Run test shortcut पर टैप करें। BudgetGo को आपके ऑटोमेशन से भुगतान मिलते ही स्टेटस सत्यापित में बदल जाता है।

संदेश

बैंक SMS अलर्ट को लेन-देन में बदलें।

यदि आपका बैंक कार्ड भुगतान और ट्रांसफ़र के बारे में टेक्स्ट भेजता है, तो संदेश ऑटोमेशन हर अलर्ट को BudgetGo की Import SMS Transaction कार्रवाई तक पहुँचा सकता है। BudgetGo संदेश आपके डिवाइस पर पढ़ता है और लेन-देन तभी बनाता है जब वह किसी वित्तीय अलर्ट को पहचानता है।

  1. 1

    संदेश ऑटोमेशन बनाएँ

    शॉर्टकट्स में Automation टैब खोलें, + पर टैप करें और Message चुनें।

  2. 2

    इसे अपने बैंक के संदेशों तक सीमित करें

    1. Sender पर टैप करके अपने बैंक का संपर्क या नंबर चुनें, या हर अलर्ट में आने वाले किसी शब्द, जैसे बैंक के नाम, के साथ Message Contains का उपयोग करें।
    2. Run Immediately चुनें, फिर Next पर टैप करें।

    फ़िल्टर को संकरा रखें। सिर्फ़ अपने बैंक से मिलान करने पर निजी बातचीत BudgetGo से बाहर रहती है।

  3. 3

    BudgetGo कार्रवाई जोड़ें

    New Blank Automation पर टैप करें, BudgetGo खोजें और Import SMS Transaction चुनें।

  4. 4

    संदेश आगे भेजें

    1. Message फ़ील्ड पर टैप करें, Select Variable चुनें, Shortcut Input चुनें और उसे Content पर सेट करें।
    2. Sender फ़ील्ड पर टैप करें और Sender पर सेट Shortcut Input चुनें। यह वैकल्पिक है, पर BudgetGo को आपका बैंक पहचानने में मदद करता है।
    3. Done पर टैप करें।
  5. 5

    टेस्ट करें

    अपने अगले बैंक अलर्ट का इंतज़ार करें, या BudgetGo के Data Hub में ऑटोमेशन का विवरण खोलकर Test connection पर टैप करें। फिर इम्पोर्ट हुआ लेन-देन देखने के लिए BudgetGo में लौटें।

समस्या निवारण

अगर कोई लेन-देन नहीं दिखे।

मुझे शॉर्टकट्स में BudgetGo की कार्रवाइयाँ नहीं मिल रहीं

इंस्टॉल या अपडेट करने के बाद BudgetGo को एक बार खोलें ताकि iOS उसकी कार्रवाइयाँ दर्ज कर ले, फिर शॉर्टकट्स में "BudgetGo" दोबारा खोजें।

मुझे "Transaction Import Failed" सूचना मिली

Wallet ऑटोमेशन ने खाली राशि या दुकान भेजी। ऑटोमेशन दोबारा खोलें और सुनिश्चित करें कि दोनों फ़ील्ड Shortcut Input का उपयोग करते हैं और Amount व Merchant चुने हुए हैं।

ऑटोमेशन चलने से पहले पूछता है

शॉर्टकट्स में ऑटोमेशन संपादित करें और Run After Confirmation से Run Immediately पर बदलें।

SMS अलर्ट से लेन-देन नहीं बना

केवल समर्थित वित्तीय संदेशों से लेन-देन बनते हैं। जाँचें कि Data Hub में इम्पोर्ट चालू हैं और Message फ़ील्ड संदेश की Content का उपयोग करता है।
