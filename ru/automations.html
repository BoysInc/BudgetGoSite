Руководство по настройке · около 2 минут на каждое

Фиксируйте траты в момент, когда они происходят.

Автоматизации «Команд» Apple могут отправлять платежи Apple Pay и банковские SMS прямо в BudgetGo, и транзакции попадают в записи без ввода. Всё работает на вашем iPhone.

Прежде чем начать

Три быстрые проверки.

  • BudgetGo установленСкачайте его из App Store и один раз войдите, чтобы его действия появились в «Командах».
  • «Команды» есть на вашем iPhoneПриложение «Команды» Apple предустановлено в iOS 17 и новее.
  • Импорт включёнВ BudgetGo откройте Data Hub и включите импорт Wallet или SMS. Если он выключен, BudgetGo игнорирует всё, что отправляет автоматизация.

Apple Wallet

Автоматически записывайте платежи Apple Pay.

Эта автоматизация срабатывает при каждой оплате картой из Wallet и отправляет сумму и магазин в действие BudgetGo Add Transaction to Budget Go.

  1. 1

    Откройте «Команды»

    Найдите и откройте приложение «Команды» на iPhone.

  2. 2

    Создайте личную автоматизацию

    Откройте вкладку Automation, затем коснитесь +, чтобы создать новую личную автоматизацию.

  3. 3

    Выберите триггер Wallet

    1. Найдите Transaction (в некоторых версиях iOS — Wallet) и выберите его.
    2. Выберите все карты, которые BudgetGo должен отслеживать.
    3. Выберите Run Immediately, чтобы автоматизация не ждала подтверждения, затем коснитесь Next.
  4. 4

    Добавьте действие BudgetGo

    Коснитесь New Blank Automation, найдите BudgetGo и выберите Add Transaction to Budget Go.

  5. 5

    Передайте данные платежа

    1. Коснитесь поля Amount, выберите Select Variable, затем Shortcut Input.
    2. Коснитесь вставленного Shortcut Input и измените на Amount.
    3. Повторите для Merchant, выбрав Merchant из Shortcut Input.
    4. Коснитесь кнопки воспроизведения для проверки, затем коснитесь Done.

    Валюта необязательна. Оставьте пустой, чтобы использовать валюту BudgetGo по умолчанию, или введите код, например USD, EUR или NGN.

  6. 6

    Проверьте в BudgetGo

    В BudgetGo откройте Data Hub и коснитесь Wallet Automation. Убедитесь, что Apple Wallet tracking включено, затем коснитесь Run test shortcut. Статус изменится на «проверено», когда BudgetGo получит платёж от вашей автоматизации.

Сообщения

Превращайте банковские SMS в транзакции.

Если банк присылает сообщения об оплатах картой и переводах, автоматизация «Сообщения» может передавать каждое уведомление в действие BudgetGo Import SMS Transaction. BudgetGo читает сообщение на вашем устройстве и создаёт транзакцию, только если распознаёт финансовое уведомление.

  1. 1

    Создайте автоматизацию «Сообщение»

    В «Командах» откройте вкладку Automation, коснитесь + и выберите Message.

  2. 2

    Ограничьте её сообщениями вашего банка

    1. Коснитесь Sender и выберите контакт или номер вашего банка либо используйте Message Contains со словом, которое есть в каждом уведомлении, например названием банка.
    2. Выберите Run Immediately, затем коснитесь Next.

    Сделайте фильтр узким. Если срабатывать будет только на ваш банк, личные переписки не попадут в BudgetGo.

  3. 3

    Добавьте действие BudgetGo

    Коснитесь New Blank Automation, найдите BudgetGo и выберите Import SMS Transaction.

  4. 4

    Передайте сообщение

    1. Коснитесь поля Message, выберите Select Variable, затем Shortcut Input и задайте Content.
    2. Коснитесь поля Sender и выберите Shortcut Input со значением Sender. Это необязательно, но помогает BudgetGo определить ваш банк.
    3. Коснитесь Done.
  5. 5

    Проверьте

    Дождитесь следующего уведомления банка или откройте сведения об автоматизации в Data Hub BudgetGo и коснитесь Test connection. Затем вернитесь в BudgetGo и проверьте импортированную транзакцию.

Устранение неполадок

Если транзакция не появилась.

Не нахожу действия BudgetGo в «Командах»

Откройте BudgetGo один раз после установки или обновления, чтобы iOS зарегистрировала его действия, затем снова найдите «BudgetGo» в «Командах».

Пришло уведомление «Transaction Import Failed»

Автоматизация Wallet отправила пустую сумму или магазин. Откройте автоматизацию заново и убедитесь, что оба поля используют Shortcut Input с выбранными Amount и Merchant.

Автоматизация спрашивает перед запуском

Измените автоматизацию в «Командах» с Run After Confirmation на Run Immediately.

SMS-уведомление не создало транзакцию

Транзакции создаются только из поддерживаемых финансовых сообщений. Проверьте, что импорт включён в Data Hub и что поле Message использует содержимое сообщения.
