খরচ যোগ করুনইনসাইটঅ্যানালিটিক্সগোপনীয়তাগাইডব্লগ অ্যাপ নিন

সেটআপ গাইড · প্রতিটি প্রায় ২ মিনিট

খরচ ঘটার মুহূর্তেই লিখে রাখুন।

Apple শর্টকাট অটোমেশন Apple Pay পেমেন্ট ও ব্যাংক SMS অ্যালার্ট সরাসরি BudgetGo-তে পাঠাতে পারে, ফলে কিছু টাইপ না করেই লেনদেন আপনার রেকর্ডে চলে আসে। সবকিছু আপনার iPhone-এ চলে।

Apple Pay payments ব্যাংক SMS অ্যালার্ট সমস্যা সমাধান
  1. আপনি পেমেন্ট করেন বা ব্যাংকের টেক্সট পানApple Pay ট্যাপ বা SMS অ্যালার্ট
  2. শর্টকাট সঙ্গে সঙ্গে চলেআপনার ব্যক্তিগত অটোমেশন
  3. BudgetGo লিখে রাখেপরিমাণ, দোকান ও ক্যাটাগরি

শুরু করার আগে

তিনটি দ্রুত যাচাই।

  • BudgetGo ইনস্টল করা আছেApp Store থেকে ডাউনলোড করে একবার সাইন ইন করুন, যাতে এর অ্যাকশন শর্টকাটে দেখা যায়।
  • শর্টকাট আপনার iPhone-এ আছেApple-এর শর্টকাট অ্যাপ iOS 17 ও পরবর্তী সংস্করণে আগে থেকেই ইনস্টল করা থাকে।
  • ইমপোর্ট চালু আছেBudgetGo-তে Data Hub খুলে Wallet বা SMS ইমপোর্ট চালু করুন। বন্ধ থাকলে অটোমেশনের পাঠানো কিছুই BudgetGo গ্রহণ করে না।

Apple Wallet

Apple Pay পেমেন্ট স্বয়ংক্রিয়ভাবে লিখে রাখুন।

Wallet কার্ড ট্যাপ করে পেমেন্ট করলেই এই অটোমেশন চলে এবং পরিমাণ ও দোকানের নাম BudgetGo-র Add Transaction to Budget Go অ্যাকশনে পাঠায়।

  1. 1

    শর্টকাট খুলুন

    আপনার iPhone-এ শর্টকাট অ্যাপটি খুঁজে খুলুন।

  2. 2

    একটি ব্যক্তিগত অটোমেশন তৈরি করুন

    Automation ট্যাব খুলুন, তারপর নতুন ব্যক্তিগত অটোমেশন তৈরি করতে + ট্যাপ করুন।

  3. 3

    Wallet ট্রিগার বেছে নিন

    1. Transaction খুঁজুন (কিছু iOS সংস্করণে Wallet হিসেবে দেখায়) এবং সেটি নির্বাচন করুন।
    2. BudgetGo যে কার্ডগুলো ট্র্যাক করবে সেগুলো সব নির্বাচন করুন।
    3. Run Immediately বেছে নিন যাতে অটোমেশন নিশ্চিতকরণের জন্য অপেক্ষা না করে, তারপর Next ট্যাপ করুন।
  4. 4

    BudgetGo অ্যাকশন যোগ করুন

    New Blank Automation ট্যাপ করুন, BudgetGo খুঁজুন এবং Add Transaction to Budget Go বেছে নিন।

  5. 5

    পেমেন্টের বিবরণ যুক্ত করুন

    1. Amount ফিল্ডে ট্যাপ করুন, Select Variable বেছে নিন, তারপর Shortcut Input নিন।
    2. যুক্ত হওয়া Shortcut Input-এ ট্যাপ করে সেটিকে Amount-এ বদলান।
    3. Merchant-এর জন্য একই করুন, Shortcut Input থেকে Merchant বেছে নিন।
    4. পরীক্ষা করতে প্লে বোতামে ট্যাপ করুন, তারপর Done ট্যাপ করুন।

    মুদ্রা ঐচ্ছিক। BudgetGo-র ডিফল্ট মুদ্রার জন্য ফাঁকা রাখুন, অথবা USD, EUR বা NGN-এর মতো কোড দিন।

  6. 6

    BudgetGo-তে যাচাই করুন

    BudgetGo-তে Data Hub খুলে Wallet Automation ট্যাপ করুন। Apple Wallet tracking চালু আছে কি না দেখে নিন, তারপর Run test shortcut ট্যাপ করুন। BudgetGo আপনার অটোমেশন থেকে একটি পেমেন্ট পেলে স্ট্যাটাস যাচাইকৃত হয়ে যায়।

বার্তা

ব্যাংক SMS অ্যালার্টকে লেনদেনে পরিণত করুন।

আপনার ব্যাংক কার্ড পেমেন্ট ও ট্রান্সফার নিয়ে টেক্সট পাঠালে, একটি মেসেজ অটোমেশন প্রতিটি অ্যালার্ট BudgetGo-র Import SMS Transaction অ্যাকশনে পাঠাতে পারে। BudgetGo বার্তাটি আপনার ডিভাইসেই পড়ে এবং আর্থিক অ্যালার্ট চিনতে পারলে তবেই লেনদেন তৈরি করে।

  1. 1

    একটি বার্তা অটোমেশন তৈরি করুন

    শর্টকাটে Automation ট্যাব খুলুন, + ট্যাপ করুন এবং Message বেছে নিন।

  2. 2

    শুধু আপনার ব্যাংকের বার্তায় সীমিত রাখুন

    1. Sender ট্যাপ করে আপনার ব্যাংকের কন্টাক্ট বা নম্বর বেছে নিন, অথবা প্রতিটি অ্যালার্টে থাকা কোনো শব্দ, যেমন ব্যাংকের নাম, দিয়ে Message Contains ব্যবহার করুন।
    2. Run Immediately বেছে নিন, তারপর Next ট্যাপ করুন।

    ফিল্টার সংকীর্ণ রাখুন। শুধু আপনার ব্যাংকের সঙ্গে মেলালে ব্যক্তিগত কথোপকথন BudgetGo-র বাইরে থাকে।

  3. 3

    BudgetGo অ্যাকশন যোগ করুন

    New Blank Automation ট্যাপ করুন, BudgetGo খুঁজুন এবং Import SMS Transaction বেছে নিন।

  4. 4

    বার্তাটি পাঠিয়ে দিন

    1. Message ফিল্ডে ট্যাপ করুন, Select Variable বেছে নিন, Shortcut Input নিন এবং সেটি Content-এ সেট করুন।
    2. Sender ফিল্ডে ট্যাপ করুন এবং Sender-এ সেট করা Shortcut Input বেছে নিন। এটি ঐচ্ছিক, তবে BudgetGo-কে আপনার ব্যাংক চিনতে সাহায্য করে।
    3. Done ট্যাপ করুন।
  5. 5

    পরীক্ষা করুন

    আপনার পরবর্তী ব্যাংক অ্যালার্টের জন্য অপেক্ষা করুন, অথবা BudgetGo-র Data Hub-এ অটোমেশনের বিবরণ খুলে Test connection ট্যাপ করুন। তারপর ইমপোর্ট হওয়া লেনদেন দেখতে BudgetGo-তে ফিরুন।

সমস্যা সমাধান

কোনো লেনদেন না দেখা গেলে।

শর্টকাটে BudgetGo-র অ্যাকশন খুঁজে পাচ্ছি না

ইনস্টল বা আপডেটের পর BudgetGo একবার খুলুন যাতে iOS এর অ্যাকশন নিবন্ধন করে, তারপর শর্টকাটে আবার "BudgetGo" খুঁজুন।

আমি "Transaction Import Failed" নোটিফিকেশন পেয়েছি

Wallet অটোমেশন খালি পরিমাণ বা দোকান পাঠিয়েছে। অটোমেশন আবার খুলে নিশ্চিত করুন দুটি ফিল্ডই Shortcut Input ব্যবহার করছে এবং Amount ও Merchant নির্বাচিত আছে।

অটোমেশন চালানোর আগে জিজ্ঞেস করে

শর্টকাটে অটোমেশন সম্পাদনা করে Run After Confirmation থেকে Run Immediately-এ বদলান।

একটি SMS অ্যালার্ট লেনদেন তৈরি করেনি

শুধু সমর্থিত আর্থিক বার্তা থেকে লেনদেন তৈরি হয়। Data Hub-এ ইমপোর্ট চালু আছে কি না এবং Message ফিল্ড বার্তার Content ব্যবহার করছে কি না দেখুন।
